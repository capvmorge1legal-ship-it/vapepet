# VapePet

Настольный питомец для Windows 10/11: котик над панелью задач со сценками (магазин, ОМОН, ревизия, вечеринка, прогулки по окнам) и полезными функциями — погода, панель (VPN, интернет, курс ЦБ, таймеры, загрузки), умный буфер обмена, «котик видит экран» (Ctrl+Shift+K), ИИ-чат, поиск остатков МойСклад.

## Установка
Скачайте `VapePet-install.zip` из последнего [релиза](../../releases/latest), распакуйте и запустите `Установить.cmd`.
Котик ставится в `Документы\VapePet`, в автозагрузку и на рабочий стол. Дальше он обновляется сам
(меню → «Настройки…» → «Обновления»).

Меню котика: правый клик по коту или **Ctrl+Shift+M** где угодно.

## Сборка
```
powershell -ExecutionPolicy Bypass -File build\build.ps1
```
Собирает `dist\VapePet.exe` из `src\*.cs` компилятором .NET Framework 4 (`csc.exe`, есть в любой Windows) и кладёт рядом установщик.

## Выпуск новой версии
1. Поднимите `AppVersion` в `src/System.cs`.
2. Отправьте изменения в `main` — GitHub Actions соберёт exe и сам опубликует релиз `vX.Y.Z`.
3. Установленные котики подтянут обновление в течение 6 часов (или сразу по «Проверить обновления»).

## Данные пользователя (в репозиторий не входят)
`%APPDATA%\VapePet.txt` — настройки (в т.ч. ключ ИИ и токен МойСклад), `VapePet_stock.tsv`, `VapePet_rates.txt`, `VapePet_crash.log`.
Замер скорости кадра: создайте `%APPDATA%\VapePet_profile.flag` — время по этапам пишется в `VapePet_profile.log`.
